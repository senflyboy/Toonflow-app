# Toonflow 商业化项目

## What This Is

Toonflow 是一款 AI 短剧/视频制作应用，能够利用 AI 技术将小说自动转化为剧本，并结合 AI 生成的图片和视频实现高效的短剧创作。

本项目旨在将现有桌面应用转型为**商业化 SaaS 产品**，采用混合部署模式（桌面应用 + 云端服务），支持多用户登录、试用额度管理、付费订阅等功能，并全面重新设计 UI 以提升用户体验。

## Core Value

让用户能够简单、快速地将小说转化为高质量的短剧/视频内容，通过 AI 自动化降低视频创作门槛。

## Context

### 技术环境

- **现有架构**: Electron 桌面应用 + Express 后端 API
- **数据库**: SQLite (本地) → 需要迁移到 PostgreSQL/MySQL (云端)
- **AI 集成**: 已集成多家 AI 提供商，通过 Vercel AI SDK 统一管理
- **前端**: 现有前端为独立项目 (Toonflow-web)，需重新设计

### 现有代码库状态

代码库映射已完成，详见 `.planning/codebase/` 目录：
- STACK.md - 技术栈详情
- ARCHITECTURE.md - 架构设计
- CONVENTIONS.md - 代码规范
- INTEGRATIONS.md - 外部集成
- TESTING.md - 测试建议
- CONCERNS.md - 技术债务和关注点

### 关键考虑

1. **数据迁移**: 从本地 SQLite 迁移到云端数据库，需要兼容现有数据结构
2. **成本控制**: AI API 调用成本需要精确计算，确保商业模式可持续
3. **安全性**: 用户数据、支付信息需要严格保护
4. **可扩展性**: 架构设计需支持未来用户增长

## Constraints

- **[架构]**: 保持混合部署模式，桌面应用需支持离线基础功能
- **[合规]**: 需要符合中国网络安全法、个人信息保护法要求
- **[支付]**: 需要集成国内主流支付方式（支付宝、微信）
- **[性能]**: AI 生成任务需要合理排队，避免 API 限流
