# Toonflow SaaS 商业化需求规格说明书

## 文档概述

本文档定义了 Toonflow 从本地桌面应用转型为商业化 SaaS 产品的完整需求规格。每个需求都有唯一的标识符，并精确映射到实现阶段。

---

## 需求分类

需求分为以下 6 个类别：

| 类别代码 | 类别名称 | 需求数量 | 实现阶段 |
|----------|----------|----------|----------|
| US | 用户系统 (User System) | 6 | Phase 1 |
| TP | 试用与付费 (Trial & Payment) | 6 | Phase 2 |
| QB | 额度与计费 (Quota & Billing) | 4 | Phase 2 |
| CS | 云端服务 (Cloud Services) | 7 | Phase 3-4 |
| AD | 管理后台 (Admin Dashboard) | 5 | Phase 5 |
| UI | UI 重新设计 (UI Redesign) | 5 | Phase 6 |
| **总计** | | **33** | |

---

## 详细需求规格

### US - 用户系统 (User System)

**实现阶段**: Phase 1

---

#### US-001: 邮箱注册

| 属性 | 描述 |
|------|------|
| **需求 ID** | US-001 |
| **标题** | 邮箱注册 |
| **描述** | 用户可以通过邮箱地址注册账户 |
| **优先级** | P0 (必须) |
| **验收标准** | 1. 用户输入邮箱和密码后成功注册<br>2. 邮箱格式验证<br>3. 密码强度验证（至少 8 位，包含大小写字母和数字）<br>4. 邮箱唯一性校验<br>5. 发送验证邮件 |
| **依赖项** | 无 |
| **测试方法** | API 测试 + 端到端测试 |

---

#### US-002: 手机号注册

| 属性 | 描述 |
|------|------|
| **需求 ID** | US-002 |
| **标题** | 手机号注册（中国） |
| **描述** | 中国用户可以通过手机号 + 短信验证码注册账户 |
| **优先级** | P0 (必须) |
| **验收标准** | 1. 用户输入手机号后获取短信验证码<br>2. 验证码有效期 5 分钟<br>3. 验证码验证通过后完成注册<br>4. 手机号格式验证（11 位中国大陆手机号）<br>5. 防刷机制（同一手机号每日最多获取 10 次验证码） |
| **依赖项** | 短信服务商集成 |
| **测试方法** | API 测试 + 短信服务集成测试 |

---

#### US-003: 用户登录

| 属性 | 描述 |
|------|------|
| **需求 ID** | US-003 |
| **标题** | 用户登录 |
| **描述** | 已注册用户可以通过邮箱/手机号 + 密码登录系统 |
| **优先级** | P0 (必须) |
| **验收标准** | 1. 支持邮箱 + 密码登录<br>2. 支持手机号 + 密码登录<br>3. 登录成功后返回 JWT token<br>4. 密码错误提示友好<br>5. 连续 5 次密码错误锁定账户 30 分钟 |
| **依赖项** | US-001, US-002 |
| **测试方法** | API 测试 + 安全测试 |

---

#### US-004: JWT 身份验证

| 属性 | 描述 |
|------|------|
| **需求 ID** | US-004 |
| **标题** | JWT 身份验证 |
| **描述** | 系统使用 JWT token 进行 API 身份验证 |
| **优先级** | P0 (必须) |
| **验收标准** | 1. Access token 有效期 15 分钟<br>2. Refresh token 有效期 7 天<br>3. Token 过期自动刷新<br>4. 未授权请求返回 401<br>5. Token 包含用户 ID 和角色信息 |
| **依赖项** | US-003 |
| **测试方法** | 安全测试 + 集成测试 |

---

#### US-005: 密码重置

| 属性 | 描述 |
|------|------|
| **需求 ID** | US-005 |
| **标题** | 密码重置功能 |
| **描述** | 用户可以通过邮箱或手机号重置忘记密码 |
| **优先级** | P1 (重要) |
| **验收标准** | 1. 用户可以通过邮箱找回密码<br>2. 用户可以通过手机短信找回密码<br>3. 重置链接/验证码有效期 30 分钟<br>4. 新密码必须符合密码策略<br>5. 密码重置后旧 token 失效 |
| **依赖项** | US-001, US-002 |
| **测试方法** | 端到端测试 |
